## Note per la revisione (App Review)

L'app non richiede login né account: tutte le funzioni sono disponibili subito.
I contenuti sono riassunti originali generati automaticamente, con link alla fonte; non viene riprodotto il testo degli articoli.
La chat usa un modello AI di terze parti (Anthropic Claude) lato server e risponde solo sulla base dell'archivio dell'app, citando le fonti. Prima dell'uso l'app spiega che le domande vengono inviate al server per generare la risposta (schermata Chiedi e informativa privacy).
La cancellazione dei dati è in Impostazioni > Cancella i miei dati.

## Etichetta privacy (App Privacy)

- Tracciamento: **No**.
- Dati raccolti, tutti **non collegati all'identità**, finalità **Funzionalità dell'app**:
  - Identificativi → ID dispositivo (identificativo casuale generato dall'app; token push se attivi le notifiche).
  - Contenuti utente → Altri contenuti utente (le domande inviate alla chat, elaborate dal fornitore AI).
- Nessun altro dato (contatti, posizione, diagnostica, utilizzo, acquisti).
